# SE-EDU Git Standard

Follow [references/git-standard.md](references/git-standard.md) whenever proposing, reviewing, or creating a commit message, and whenever naming a branch in this repository. Read the reference completely before performing one of those tasks.

Before drafting a commit message, inspect the relevant diff and repository state. Describe the actual change and its reason. Do not infer a reason that the diff and user request do not support.

Before creating a commit, check the complete subject and body against the reference. If the change is non-trivial, include a body. Keep separate concerns in separate commits when the user has authorised that commit structure.

This skill does not authorise creating a branch, committing, pushing, rewriting history, or changing Git configuration. Obtain the authority required by the repository instructions and the user's request.
