# SE-EDU Java Coding Standard

Follow the project rules in [references/java-coding-standard.md](references/java-coding-standard.md) for every Java source and test file created or changed in this repository.

Before editing Java, read the reference completely. During review, report concrete violations with the affected file and rule. When changing code, preserve behaviour unless the user also requests a behaviour change.

For topics that the reference does not cover, follow the [Google Java Style Guide](https://google.github.io/styleguide/javaguide.html), as required by the SE-EDU standard.

Use American spelling in Java comments and Javadoc because the SE-EDU standard requires it. Continue to use the repository's required UK English for prose outside Java code.
